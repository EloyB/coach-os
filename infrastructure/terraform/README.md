# Terraform / OpenTofu — coach-os infrastructure

OpenTofu (or Terraform) configuration that provisions every Scaleway resource
coach-os needs: VPS, reserved IP, security group, container registry, managed
Postgres, transactional email domain, secret manager entries, and DNS records.

## Prerequisites

1. **OpenTofu installed** — `winget install OpenTofu.Tofu`
2. **Scaleway CLI installed** — `winget install Scaleway.Scaleway-CLI`
3. **A new Scaleway organization + project** for coach-os (separate from amare)
4. **An IAM API key** in that org with `IAMFullAccess` + `RegistryFullAccess` +
   `RDBFullAccess` + `InstanceFullAccess` + `TEMFullAccess` + `SecretManagerFullAccess`
   + `DomainsFullAccess` + `ObjectStorageFullAccess`
5. **`coach-os.be` registered in Scaleway Domains**

## One-time bootstrap

State lives in a Scaleway Object Storage bucket. Terraform can't manage its own
state store (chicken-and-egg), so create it once via the CLI:

```powershell
# Authenticate the Scaleway CLI for the new org
scw init

# Create the state bucket
scw object bucket create coach-os-tf-state region=fr-par
```

## Per-machine setup

```powershell
# Set the credentials Terraform will use (also used by the s3 backend)
$env:SCW_ACCESS_KEY = "SCW..."        # IAM access key
$env:SCW_SECRET_KEY = "00000000-..."   # IAM secret key

# Generate a deploy SSH key (used later by GitHub Actions, also baked into the VPS)
ssh-keygen -t ed25519 -C "gha-deploy@coach-os" -f $env:USERPROFILE\.ssh\coach-os-gha

# Copy the example tfvars and fill in real values
Copy-Item terraform.tfvars.example terraform.tfvars
notepad terraform.tfvars
```

## Apply

```powershell
tofu init     # downloads providers, configures backend
tofu plan     # review what will be created
tofu apply    # creates everything (~3-5 min)
```

## After apply

```powershell
tofu output                       # shows VPS IP, registry endpoint, etc.
tofu output -raw vps_ip           # for scripting
tofu output -raw vps_instance_id  # add this to GitHub Secret SCALEWAY_INSTANCE_ID
```

Then proceed to VPS bootstrap (`scripts/bootstrap-vps.sh`) and GitHub Secrets
setup (see `infrastructure/SECRETS.md`).

## Day-2 operations

- **Rotate JWT key:** `tofu apply -replace=random_password.jwt_key`
- **Resize VPS:** edit `vps_instance_type` in `terraform.tfvars`, `tofu apply`
- **Resize DB:** edit `db_node_type`, `tofu apply` (Scaleway does in-place)
- **Add a staging environment:** copy this folder to `terraform-staging/`,
  point at a different state-key prefix in `backend.tf`, change names + IPs
- **Destroy everything (DANGER):** `tofu destroy` — irreversible. The DB
  goes with it. Take a `pg_dump` first.

## What's NOT in here (manual steps)

- Domain registration (buy `coach-os.be` at Scaleway Domains)
- TEM SMTP credentials — generated by Scaleway after DKIM verification;
  paste them into the `Email__Username` / `Email__Password` secrets
  manually (or extend this Terraform with `scaleway_iam_api_key` + tag)
- Let's Encrypt SSL — handled inside the VPS by `bootstrap-vps.sh` via certbot
- GitHub Actions secrets — set them in the GitHub UI per `SECRETS.md`
- **Mollie Connect OAuth credentials** — after `tofu apply` lege secrets
  `Mollie__ClientId` en `Mollie__ClientSecret` aanmaakt, vul je deze manueel in
  na het aanmaken van het Mollie partner-account en het activeren van Mollie
  Connect. Redirect URI in Mollie dashboard: `https://app.coach-os.be/api/oauth/mollie/callback`
  (+ `http://localhost:5142/api/oauth/mollie/callback` voor dev).
  Vul in via:
  ```powershell
  scw secret secret-version create <secret_id> data=<value>
  ```
  Of via de Scaleway console.
